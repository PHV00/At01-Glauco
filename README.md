# 📖 Contexto

Esta atividade possui dois objetivos principais:

### 1️⃣ Uso estruturado de IA
Realizar o primeiro contato estruturado com **IA como ferramenta de desenvolvimento de software**, incluindo:
- Planejamento  
- Implementação  
- Revisão  
- Testes  

### 2️⃣ Revisão prática de Estruturas de Dados I
Revisar os conceitos por meio de **problemas clássicos de entrevistas técnicas**.

A atividade será desenvolvida durante os feriados e revisada em sala no dia **30/mar**, com apresentação por equipe.

# 💻 Parte 2 — Desafios de Programação (Obrigatório)

Selecionar problemas no estilo **code interview** utilizando as estruturas estudadas.

---

## 🌐 Plataformas Permitidas

- LeetCode  
- HackerRank  
- CodeSignal  
- CodeWars  
- NeetCode  
- GeeksForGeeks  
- CSES Problem Set  
- AtCoder (nível iniciante)  
- Beecrowd (URI)  
- AlgoExpert (se houver acesso)  

---

# 📊 Quantidade Obrigatória

Cada equipe deve resolver **exatamente 12 problemas**, distribuídos assim:

- ✅ **5 problemas de Arrays**
- ✅ **4 problemas de Listas Encadeadas**
- ✅ **3 problemas de Pilhas**

---

## 📌 Regras Importantes

- Problemas devem ser preferencialmente de nível **fácil ou médio**  
- Pelo menos **50% devem ser de nível médio**
- Não pode haver repetição de problemas dentro da equipe
- Cada integrante deve resolver **no mínimo 3 problemas**
- Todo código deve estar no **GitHub da equipe**
- Todos os membros devem ter **commits realizados**
- Cada aluno deve realizar **entrega individual**, mesmo sendo trabalho em equipe

---

# 📄 Para Cada Problema, Incluir no Relatório

- **Nome do problema**
- **Link do problema**
- **Plataforma**
- **Estrutura de dados principal utilizada**
- **Justificativa**
  - Por que essa estrutura é adequada?
  - Qual a complexidade da solução?
